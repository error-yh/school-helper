# S8-WIDGET-01 最终结项报告

## 功能与界面

v0.2.2 新增 Android 桌面「今日课程」。组件读取活动课表，按真实开始时间显示最多两门未结束课程。开课前 10 分钟显示「即将开始」，开课后显示「进行中」，下课后重新选择剩余课程。当日无剩余课程时可查看明天第一门。点击课程打开对应详情。

最终界面采用单层圆角卡片、浅分隔线、固定右对齐时间列和标题旁的轻量状态标签，支持 4×2、4×3 与系统深浅色。长课程名按空间省略，时间列保持对齐。

## 课表与调度

组件复用课表有效安排和教学周规则。时间由自定义作息和生效的调课、停课、补课解析。所有实例共用一个非精确 RTC_WAKEUP 闹钟，按可见课程的下一状态变化或日期切换安排更新。回调时重新查询活动课表并按当时的时间重算。应用打开、数据变化和系统事件也可触发同步。Room Schema 保持 5。

## 验证

- 52 项发布相关 JVM 测试通过。Release Lint 为 0 错误、71 警告。

- vivo V2271A 的正式 v0.2.1 同签名原位升级到 v0.2.2。首次安装时间保留，课程和设置页可见内容的指纹一致，课表、快递和身份码入口可打开。正式桌面组件显示原有课程并打开对应详情。临时 Android 用户中验证了正式包的空数据首次启动，测试后已清理临时用户。
