# Raster orientation source audit

No new production dependency, native library, model or copied upstream implementation is included by B4b. The host and the newly written Kotlin remain GPL-3.0-only. Android BitmapFactory and PdfRenderer are platform APIs. The proposed AndroidX EXIF dependency was removed before acceptance.

The exact examined mature reader was `androidx.exifinterface:exifinterface:1.3.7`, Copyright 2018/2020 The Android Open Source Project, Apache-2.0. Public source archive: <https://dl.google.com/dl/android/maven2/androidx/exifinterface/exifinterface/1.3.7/exifinterface-1.3.7-sources.jar>. SHA-256 `04c0a6d2ff9745ab9946ebcdd2cf35889e05c79e5218e8b59a57a98a2670dc74`. The cached AAR SHA-256 is `0e8f1832266c5b0667ad3d3b1098e624e49a09075493a014a7e88af01fd30ad3`. The POM declares Apache-2.0 and only androidx.annotation 1.2.0 at runtime; the AAR has no native libraries or standalone notice file.

Read-path audit of `androidx/exifinterface/media/ExifInterface.java`: JPEG allocation at 5627 uses the bounded 16-bit APP1 length, but TIFF attribute allocation at 6940 uses declared component counts before readFully; PNG eXIf allocation at 6150 uses the declared chunk length before counted reading; thumbnail allocations at 7088, 7137 and 7167 follow indirect length values. A 12 MB file cap therefore does not bound these allocations. `loadAttributes` at 4622 catches malformed-metadata exceptions and compatibility defaults at 6718 insert orientation zero. Debug mode at 4653 prints arbitrary metadata values. `ExifInterfaceUtils.java` was also reviewed; its copy helpers are not a protection for these earlier allocations.

The approved adjustment uses an original, deliberately narrow JPEG/PNG container and IFD0-orientation utility. It checks actual input ranges, fixed work limits, CRC for PNG eXIf and the single inline SHORT orientation value. It does not follow any TIFF directory pointer, thumbnail or unrelated payload, and never invokes ExifInterface. This is not a general EXIF/TIFF validator. Missing orientation means identity; malformed relevant structure or duplicate orientation/EXIF fails closed. No source archive, AAR, or unused Apache license file is added to the app. Root's formal plan adjustment records the independent newer-version audit and authorization.
