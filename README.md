## 今日课程小组件

安装或升级后，打开校园助手一次。在 Android 桌面长按空白处，进入「小部件」，在校园助手下找到「今日课程」并添加。长按组件可调整大小。

小组件读取当前课表，显示最多两门未结束的课程。下课后自动递补，今天无剩余课程时可预览明天第一门。点击课程可打开对应详情。Android 省电、息屏和后台调度策略可能延迟刷新，重新打开 App 时会同步。

保留课表、快递、身份码、我的四个入口，以及手动单次调整、停课、补课、历史和受保护撤销。文字通知导入/调课界面已取消，如意邻里已移除；应用内原作者自动更新源关闭。
